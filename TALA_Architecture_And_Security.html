🌐

GitHub SSL/TLS & CDN

תעודת SSL/TLS אוטומטית (HTTPS בלבד), פריסת CI/CD ב-OIDC, שער בדיקת נוכחות (Presence Gate) ו-105 בדיקות יחידה.

🔐

אימות שרת ופרוקסי AI מוגן

אימות סיסמה בענן (talaLogin + Custom Token), גיבוב SHA-256 (256 rounds + Salt), ופרוקסי aiGenerateV2 המסתיר מפתחות API.

🛡️

בקרת גישה ובידוד נתונים

אכיפת שרת (firestore.rules): חסימת גישה אנונימית (403), בידוד לפי ownerEmail, שיתוף צוותי מבוקר וטוקן חד-פעמי ממודר להורים.

🕵️‍♀️

הגנת פרטיות הקטין (PII)

המרה אוטומטית לראשי תיבות (נ.י.) והשחרת ת.ז/טלפון/כתובת (████████) בהדפסה, ב-Word, ב-PDF, במייל ובהעתקה למנב"ס.

💻

Secured Code & Offline PWA

עבודה רציפה אופליין (IndexedDB + sw.js), מיזוג ענן ברמת שדה ללא דריסות הדדיות, וחילוץ אבחונים מקומי בזיכרון הדפדפן.

עקרון מנחה – הגנה רב-שכבתית (Defense-in-Depth): אבטחת המערכת משלבת הצפנת תקשורת (TLS 1.3), אימות ופרוקסי AI בפונקציות ענן (Cloud Functions), אכיפת חוקים בשרת (Firestore Rules), סנכרון טרנזקציוני ברמת שדה והנדסת פרטיות השומרת על הקטין בכל שלב.

1. ארכיטקטורת המערכת מקצה לקצה (High-Level System Architecture Diagram)

ארכיטקטורת Serverless SPA ו-Offline PWA המפרידה בין שכבת הלקוח, פונקציות הענן המאובטחות, מסד הנתונים ושירותי ה-AI

System Architecture Diagram

1. שכבת GitHub & SSL Edge

אירוח סטטי על GitHub Pages CDN ב-SSL/TLS 1.3. פריסה אוטומטית רק לאחר מעבר 105 בדיקות יחידה ובדיקת Presence Gate (אפס משתמשים פעילים).

2. שכבת לקוח ו-Offline PWA

אפליקציית React 19 עם IndexedDB Offline Cache, חילוץ אבחונים מקומי בדפדפן, השחרת PII אוטומטית, הפקת PDF/Word וגשר העתקה למנב"ס/משו"ב.

3. שכבת ענן (Firebase)

אימות שרת ב-talaLogin, סנכרון טרנזקציוני ברמת שדה ב-Firestore ללא דריסת עבודת עמיתים, וטוקן חד-פעמי ממודר לקול ההורים (tala_invites).

4. פרוקסי AI ודיוור מבוקרים

קריאות AI מנותבות דרך פונקציית ענן aiGenerateV2 המאמתת Firebase ID Token ומגבילה מכסות יומיות, ללא חשיפת מפתח Gemini בדפדפן.

Authentication & Session Flowchart

🔑 אימות שרת וגיבוב רב-סבבי (talaLogin + PBKDF)

פונקציית הענן talaLogin מאמתת את קוד הגישה בשרת עם 128-bit Salt ו-256 סבבי SHA-256 (TALA_PBKDF_V1) ומנפיקה Firebase Custom Token מבלי לחשוף את מאגר המשתמשים לדפדפן.

3. אבטחת תשתית: תעודת SSL ב-GitHub, צינור CI/CD וחוקי Firestore

הגנה מלאה על התעבורה ברשת (Data in Transit), תהליך הבנייה והפריסה (DevSecOps), ואכיפת הרשאות בענן (Data at Rest)

GitHub SSL • OIDC CI/CD • Firestore Rules

🌐 תעודת SSL/TLS רשמית של GitHub TLS 1.3

האפליקציה מתארחת על תשתית GitHub Pages המוגנת באמצעות רשת ה-CDN העולמית של Fastly ותעודת SSL מנוהלת:

  • תעודת X.509 SSL מנוהלת ומתחדשת אוטומטית: מונפקת ע"י רשות אישורים מוסמכת (Let's Encrypt / DigiCert) ומותקנת אוטומטית על הדומיין zivitreshef.github.io.
  • כפיית HTTPS מוחלטת (Enforce HTTPS): כל פנייה ב-HTTP מופנית אוטומטית (301 Redirect) לערוץ מוצפן ב-TLS 1.2 / TLS 1.3, כולל כותרות HSTS למניעת מתקפות SSL Stripping ו-MITM.
  • אפס משטח תקיפה צד-שרת: מכיוון שהאתר מוגש כנכסים סטטיים חתומים בלבד (Immutable Static Bundle + PWA Service Worker), לא קיים שרת אפליקטיבי החשוף ל-SQL Injection או RCE.

⚙️ אבטחת תהליך הבנייה (GitHub Actions) deploy.yml

תהליך הפריסה מוגדר בקובץ .github/workflows/deploy.yml ופועל לפי עקרונות Zero-Trust CI/CD:

  • הרשאות מינימליות ואימות OIDC: ה-Workflow פועל עם טוקן זמני (OpenID Connect) והרשאות contents: read ו-pages: write בלבד – ללא סודות קבועים.
  • שער בדיקת נוכחות פעילה (Presence Safety Gate): הסקריפט npm run check-presence בודק מול הענן שאין אנשי צוות פעילים ב-15 הדקות האחרונות לפני ביצוע מיזוג ופריסה.
  • שער איכות אוטומטי (105 בדיקות יחידה): הפקודה npm run test:run מריצה 105 בדיקות אוטומטיות ב-10 חבילות בדיקה (Vitest); כישלון בבדיקה עוצר את הפריסה מיידית.

☁️ פונקציות ענן וחוקי אבטחה (Cloud & Rules) firestore.rules

בסיס הנתונים ושירותי ה-AI מוגנים בשכבת שרת ב-Google Cloud (AES-256 במנוחה + אימות חוקים):

  • אימות שרת ופרוקסי AI מוגן (talaLogin & aiGenerateV2): אימות הסיסמאות והנפקת Custom Token מתבצעים בשרת. קריאות ל-Gemini עוברות דרך aiGenerateV2 עם אימות Bearer JWT ובקרת מכסות ללא חשיפת מפתח ה-API.
  • נעילת הגדרות ומשתמשים (tala_config Lockdown): קובץ tala_config/allowed_users נעול לקריאה ולכתיבה בצד הלקוח (Admin בלבד).
  • בידוד תיקי תלמידים וטוקן הורים (Scoped Access): כרטיסי tala_students נגישים רק ל-ownerEmail או ל-sharedWith. אוסף tala_invites מאפשר להורים גישה נקודתית לטוקן חד-פעמי בלבד.
🔒 הצפנה מקצה לקצה בכל ערוצי התקשורת (End-to-End Encrypted Channels): בין דפדפן המורה ל-GitHub Pages (HTTPS TLS 1.3) • בין הדפדפן ל-Cloud Firestore ול-Cloud Functions (Encrypted gRPC/HTTPS over TLS) • בין פרוקסי הענן ל-Gemini AI (Server-to-Server TLS).

4. גישת פיתוח קוד מאובטח והנדסת פרטיות (Secured Code Attitude)

עקרונות כתיבת קוד הגנתי (Defensive Programming), פרוקסי AI, מיזוג רב-מקצועי ברמת שדה והשחרת PII אוטומטית

Secured Code Attitude & Privacy by Design

1. אימות שרת, פרוקסי AI מוגן והיגיינת סיסמאות functions/index.js

  • פרוקסי AI מאובטח בענן (aiProxyClient.js + aiGenerateV2): מפתח ה-Gemini נשמר ב-Secret Manager בשרת בלבד. כל בקשה מאומתת עם Firebase ID Token (Bearer JWT) ועוברת בקרת מכסה יומית ומצטברת.
  • גיבוב קריפטוגרפי תקני (FIPS 180-4 SHA-256): מימוש עצמאי של 256 סבבי גיבוב עם Salt ייחודי והגירה אוטומטית (ensureUsersListPasswordsHashed) המסירה כל טקסט גלוי.
  • טוקנים חד-פעמיים לקול ההורים (parentInvite.js): יצירת טוקן אקראי קריפטוגרפי (16-char Hex) המופרד לחלוטין מתיק התלמיד וננעל אוטומטית לאחר שליחת שאלון ההורים.

2. הנדסת פרטיות, גשר מנב"ס וקליטת אבחונים מקומית privacyAndAcronyms.js

  • ברירת מחדל מחמירה (Secure by Default): הדגל hideDetailsInPrint = true מופעל אוטומטית בכל שלושת הדוחות וכן בגשר ההעתקה למנב"ס/משו"ב (ministryCopyFormatter.js).
  • סריקה והחלפה חכמה בתוך טקסט חופשי: הפונקציה redactStudentNameInText מזהה את שם התלמיד בכל הפרקים, המטרות, התצפיות ודו"ח המצב ומחליפה אותו בראשי תיבות (נ.י.) לצד השחרת ת.ז/טלפון (████████).
  • חילוץ אבחונים בזיכרון הדפדפן (diagnosticIntake.js): קובצי PDF וטקסט של אבחונים מפוענחים מקומית בדפדפן המורה ללא שמירת הקובץ בענן, ורק טקסט פדגוגי מסונן נשלח לניתוח מטרות.

3. עמידות Offline PWA ומיזוג רב-מקצועי ברמת שדה studentSyncMerge.js

  • מיזוג ענן טרנזקציוני ללא דריסות (Field-Level Merge): הפונקציה mergeStudentRecordsForSync ממזגת שינויים של אנשי צוות שונים ברמת השדה והמטרה הבודדת (כולל leadRole ותצפיות) בתוך טרנזקציית Firestore.
  • עבודה רציפה ללא אינטרנט (Offline-First PWA): שילוב של persistentLocalCache ב-IndexedDB עם Service Worker (public/sw.js) ועטיפות safeStorage מוגנות.
  • מניעת דליפת מידע בשגיאות (ErrorBoundary): לכידת שגיאות ריצה והצגת מסך שחזור מבוקר בעברית מבלי לחשוף נתוני תלמיד.

4. אכיפת הרשאות ב-Domain, הגנת תצפיות ו-105 בדיקות domain/permissions.js

  • הפרדת הרשאות קשיחה בקוד (Single Source of Truth): פונקציות canViewStudent, canDeleteStudent ו-canLockReport מוודאות שרק היוצר המקורי (ownerEmail) רשאי לנעול, לארכב, לשתף או למחוק.
  • הגנה על עריכות ותצפיות מפני דריסת AI: מטרות שנערכו ידנית או כוללות מיקרו-תצפיות כיתתיות (goalObservations.js) מוגנות אוטומטית מפני דריסה בעיבוד AI חוזר.
  • 105 בדיקות יחידה אוטומטיות (10 Test Suites): כיסוי מלא של גיבוב, הרשאות, השחרת PII, קול ההורים, גשר מנב"ס, תצפיות, מיזוג רב-מקצועי וקליטת אבחונים.
