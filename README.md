# TALA – מערכת תכנית עבודה משותפת ואינטגרטיבית ברוח הגישה האקולוגית ותח"י

מערכת Web אינטראקטיבית (בעברית מלאה – RTL) לבניית תכנית עבודה אקולוגית ותח"י עבור גננות, מורות שילוב וצוותי מתי"א.

## תכונות מרכזיות
- **בקרת גישה לרשימת משתמשים מורשים בלבד (Allowed Users List)**: רק משתמשים המופיעים ברשימת המורשים (`src/allowedUsers.js`) יכולים להתחבר למערכת. כולל ממשק ניהול מורשים למנהל/ת המערכת.
- **מאגר מטרות ויעדים דינמי (Dynamic Usage Goal Bank)**:
  - מבוסס על תבנית הגישה האקולוגית ועל מאגר מטרות ויעדים לבניית תח"י (מתי"א ר"ג).
  - כל מטרה חדשה נשמרת לשימוש עתידי ומדורגת אוטומטית לפי שכיחות שימוש (הנפוצות ביותר בראש הרשימה).
- **עד 3 שאלות מנחות ב-AI (Facilitating Questions)**: בעת בחירה או הגדרה של מטרה עליונה (HL Goal), המערכת שואלת עד 3 שאלות מנחות המסייעות למורה לדייק ולמלא אוטומטית את 6 עמודות המטרה.
- **תיבת טקסט חופשי + כפתור Submit ליצירת טבלת סיכום בראש המסמך**: שילוב הטקסט החופשי של המורה וכלל המטרות לחילול אוטומטי של טבלת `מוקדי כוח: כוחות קיימים` מול `כוחות להעצמה וחיזוק`.
- **הדפסה עם הגנת פרטיות (ברירת מחדל: מסומן)**: תיבת סימון לצד כפתור ההדפסה המחליפה את שם הילד לראשי תיבות (גם בכותרת וגם בגוף הטקסט) ומשחירה פרטים מזהים (ת.ז, ת.ל, כתובת, טלפון).
- **קול ההורים (קישור חד-פעמי למובייל)**: הכפתור "קול ההורים" בסעיף 1 יוצר קישור אישי (תקף 7 ימים) שנשלח להורים בוואטסאפ. ההורים עונים על 3 שאלות קצרות בלי התחברות, והתשובות משולבות בלחיצה אחת בתיאור החופשי של המורה. אין שדות חדשים בכרטיס התלמיד, והתשובות לא נכנסות לתוכנית בלי אישור המורה. הקישור הציבורי הוא `#/share-input/<token>`, והנתונים נשמרים באוסף `tala_invites` (כללי אבטחה ב-`firestore.rules`).

## הרצה מקומית
```bash
npm install
npm run dev          # פיתוח מקומי (מתחבר ל-Firestore של הפרודקשן)
npm run test:run     # בדיקות יחידה
```

## פריסת Firebase (פעולות נפרדות מפריסת האתר)
```bash
firebase deploy --only firestore:rules   # כללי אבטחה
firebase deploy --only auth              # הפעלת התחברות Email/Password (firebase.json)
```
לפני פרסום האתר: `npm run check-presence` (דורש 15 דקות ללא פעילות משתמשים).

## פריסה לאתר Frontend ב-GitHub Pages (`https://github.com/zivitreshef/TALA`)
הפרויקט כולל תהליך GitHub Actions מובנה (`.github/workflows/deploy.yml`).
לאחר דחיפת הקוד לענף `main` בריפוזיטורי `https://github.com/zivitreshef/TALA`:
1. היכנסי ב-GitHub אל **Settings -> Pages**.
2. תחת **Build and deployment -> Source**, בחרי **GitHub Actions**.
3. האתר יעלה אוטומטית בכתובת: `https://zivitreshef.github.io/TALA/`.
