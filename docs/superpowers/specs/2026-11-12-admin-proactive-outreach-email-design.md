# מסמך תכנון: מנגנון שליחת מיילים יזומים למורים ממרכז הבקרה

**תאריך:** 12 בנובמבר 2026  
**ענף:** `feat/admin-proactive-outreach-email`  
**סטטוס:** טיוטה לאישור

---

## 1. רקע ומטרת המערכת

מנהלת המערכת זקוקה ליכולת יזומה של שמירה על קשר שוטף ("Keep in Touch") מול מורות וגננות הפועלות במערכת TALA, ובפרט מורות שנמצאות לקראת סיום תקופת הניסיון (למשל נותרו 3 ימים). המטרה היא להציע סיוע, לבדוק האם משהו אינו ברור, לסייע בהתמודדות עם קשיים ולספק מענה פדגוגי ואישי חם ומקצועי.

המיילים יישלחו ישירות מתוך מרכז הבקרה, בפורמט HTML מעוצב הכולל את לוגו המערכת, פלטת הצבעים הרשמית (כחול-סגול עמוק, פסים צבעוניים בסגנון ויטראז'), וכפתור כניסה ישיר למערכת.

---

## 2. יעדים, אי-יעדים ואיסורים

### יעדים
1. **בחירה מרובה בטבלה**:
   - הוספת עמודת תיבת סימון (Checkbox) בטבלת המשתמשים במרכז הבקרה.
   - תיבת "בחר הכל" בראש הטבלה, המסמנת או מבטלת את כל המשתמשים המוצגים תחת הסינון הנוכחי (למשל לשונית "משתמשי ניסיון").
   - סרגל פעולה צף ומודגש מעל הטבלה ברגע שיש לפחות משתמש אחד מסומן: `נבחרו X מורים | שליחת מייל יזום`.
   - כפתור פעולה מהיר לכל שורת משתמש בודדת (אייקון מעטפה).

2. **מודאל עריכת הודעה ותבניות**:
   - הצגת רשימת הנמענים שנבחרו עם כפתור הסרה מהיר (תגית מחיקה `✕` לכל נמען).
   - תפריט בחירת תבניות מוכנות מראש:
     - **תבנית 1: סיום תקופת ניסיון והצעת סיוע**: מתאימה למורות עם יתרת ימי ניסיון (פונה לפי `{name}` ומציינת `{remainingDays}`).
     - **תבנית 2: בדיקת שביעות רצון וקשר שוטף**: בדיקה שגרתית כיצד העבודה בתוכנית וסיוע.
     - **תבנית 3: הודעה מותאמת אישית חופשית**: מאפשרת למנהלת להזין כל טקסט ונושא שתרצה.
   - עורך נושא הודעה ועורך תוכן הודעה עם תמיכה בהחלפת משתנים דינמיים פר-מורה (`{name}`, `{remainingDays}`, `{group}`).
   - תצוגה מקדימה חיה המציגה בדיוק כיצד המייל והלוגו ייראו אצל המורה ב-HTML.

3. **שליחת HTML מעוצב עם לוגו המערכת**:
   - פונקציה חדשה ב-`emailService.ts`: `buildAdminOutreachEmailHtml` ו-`sendAdminOutreachEmailInBackground`.
   - הטמעת לוגו רשמי ברזולוציה גבוהה (`https://zivitreshef.github.io/TALA/tala-logo.png`).
   - עיצוב נקי ברוח `buildOnboardingInvitationHtml` (פס צבע עליון, כותרת יוקרתית, גוף הודעה מרווח עם כפתור כניסה ישיר למערכת וקרדיט מערכת).
   - תמיכה מלאה ב-RTL (יישור לימין, עברית טבעית ותקנית).

4. **שליחה סדרתית מבוקרת**:
   - שליחת המיילים אחד אחרי השני (ולא כולם במקביל) עם השהייה קצרה (300ms) למניעת עומס או חסימות ב-Google Apps Script / EmailJS.
   - מד התקדמות ברור בזמן אמת (`שולח מייל 3 מתוך 5 אל שרה כהן...`).
   - דוח סיכום בסיום (`5 מתוך 5 מיילים נשלחו בהצלחה!`).
   - תיעוד אוטומטי בענן דרך `recordEmailAuditLogToCloud`.

### אי-יעדים
- אין צורך במערכת דיוור שיווקי המוני – השליחה מבוצעת באמצעות מנוע המייל הקיים והמאושר של TALA (Google Apps Script Relay).
- אין צורך בתזמון אוטומטי ב-Cron (מדובר בפעולה יזומה ומבוקרת של מנהלת המערכת מתוך הממשק לפי שיקול דעתה).

### איסורים ועקרונות מחייבים
- **ללא סוגריים באנגלית**: כל הכותרות, התוויות, הכפתורים והתבניות ייכתבו בעברית נקייה ללא סוגריים באנגלית (לפי כלל הברזל של TALA).
- **אבטחה וסניטציה**: בדיקת תקינות כתובות אימייל, מניעת הזרקת שורות בנושאים, והגנה על פרטיות.
- **פשטות מרבית**: פשטות ואינטואיטיביות מרבית למנהלת המערכת – בחירה, לחיצה, עריכה קלה ושליחה.

## 3. ארכיטקטורה ורכיבים טכניים

### א. מודול השירות: `src/emailService.ts`
1. הגדרת ממשק נתונים:
   ```typescript
   export interface AdminOutreachEmailParams {
     teacherName: string;
     teacherEmail: string;
     remainingDays?: number | null;
     group?: string;
     subject: string;
     messageContent: string;
     siteUrl?: string;
   }
   ```
2. פונקציית הפקת ה-HTML:
   `buildAdminOutreachEmailHtml(params: AdminOutreachEmailParams): string`
   - כוללת את הלוגו הרשמי של TALA.
   - מכילה כותרת ראשית ופס ויטראז' עליון.
   - מעבדת שורות חדשות לפסקאות HTML מעוצבות.
   - כפתור הנעה לפעולה: `כניסה למערכת TALA`.
3. פונקציית שליחה:
   `sendAdminOutreachEmailInBackground(params: SendAdminOutreachEmailParams): Promise<{ ok: boolean; provider: string }>`

### ב. מודאל חדש: `src/components/modals/AdminOutreachEmailModal.tsx`
- **מאפיינים (Props)**:
  - `recipients`: רשימת משתמשים שנבחרו (`AllowedUserRecord[]`).
  - `onClose`: סגירת המודאל.
  - `onRemoveRecipient`: הסרת נמען ספציפי מהרשימה.
  - `onSuccess`: הודעת סיום למרכז הבקרה.
- **מצב פנימי (State)**:
  - `selectedTemplateKey`: מפתח תבנית ('trial_ending' | 'satisfaction' | 'custom').
  - `subjectTemplate`: שורת הנושא.
  - `bodyTemplate`: גוף ההודעה עם משתנים.
  - `previewUser`: המשתמש שעבורו מוצגת התצוגה המקדימה.
  - `isSending`: האם מתבצעת שליחה כרגע.
  - `sendProgress`: `{ current: number; total: number; currentName: string }`.
  - `sendResults`: סיכום הצלחות ושגיאות.

### ג. אינטגרציה בטבלה: `src/components/modals/AdminAllowlistModal.tsx`
- הוספת `selectedUserIds: Set<string>`.
- עמודת Checkbox לכל שורה עם כפתור "בחר הכל" בכותרת העמודה.
- סרגל פעולה צף / עליון: `נבחרו X משתמשים [שליחת מייל יזום] [בטל בחירה]`.
- הוספת אייקון שליחת מייל מהיר בכל שורת משתמש (פותח את המודאל עבור אותו משתמש ספציפית).
